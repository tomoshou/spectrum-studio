# Spectrum Studio

音声ファイルをドラッグ＆ドロップして、スペクトラム（音の波形・バー）の映像をつくり、MP4 や PNG に書き出すツール。ブラウザだけで動き、音声はどこにもアップロードされない（すべて手元のブラウザ内で処理される）。

**→ https://tomoshou.github.io/spectrum-studio/**

## できること
- 線形バー（中央／下／上揃え）、円形バー（外・内・内外対称）、波形、円形波形などのスタイル
- 本数・幅・高さ・回転・ミラーなどの形状調整、感度／スムージング／周波数範囲の調整
- 単色・グラデーション・虹色の着色、発光、背景色・背景画像、透明背景（PNG のみ）
- 16:9 / 1:1 / 9:16 のキャンバス、24/30/60fps で MP4（H.264 + AAC）書き出し

## 動作環境
- MP4 の書き出しには WebCodecs が必要。**Chrome / Edge 推奨**（Safari や一部のスマホでは書き出しが使えないことがある）
- 再生プレビューと PNG 書き出しは、おおむねどのブラウザでも動く

## 使い方
1. 上記 URL を開く（または `spectrum_studio.html` をブラウザで直接開く）
2. 音声ファイルをドロップする
3. 左のプレビューを見ながら右のパネルで調整する
4. 「MP4 を高速書き出し」または「PNG スナップショット」で保存する

1 ファイル完結の HTML（外部ライブラリの読み込みも通信もなし）。MP4 の組み立てには [mp4-muxer](https://github.com/Vanilagy/mp4-muxer)（MIT）を同梱している。
